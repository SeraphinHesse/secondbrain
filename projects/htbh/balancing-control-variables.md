# Balancing Approach — Control Variables

Source: Conversation with Silvius

## Core Idea
Remove randomness from the system during balancing testing to more accurately predict player behavior and positioning.

## Process
1. Strip out random variables → establish controlled baseline
2. Test and balance against predictable, stable conditions
3. Reintroduce randomness incrementally once the core system is well understood

## Relevance
Applicable to HtbH balancing pipeline — helps isolate core system behavior before layering in variable/emergent complexity.
