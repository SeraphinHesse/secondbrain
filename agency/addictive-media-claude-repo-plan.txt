PROJECT AREAS
=============

1. AUTOMATED CLIENT OUTREACH

   - Auto-outreach based on what's on their website
   - Mirror their tone in responses

2. ADDICTIVE MEDIA DASHBOARD (task + project management)
   - Accessible to everyone on the team
   - Stage 1: runs over the GitHub repo — pull to access files locally
   - Stage 2: real server setup with mobile version
   - Features: task management, calendar management, general project management
   - Boilerplate project setup for each new client/project

3. DOCUMENT CREATION
   - Skills/tools to create boilerplate docs from templates
   - High-quality slides and presentations for the consulting side
   - PDF reports and documents
   - Facebook Ads Manager data automation → auto-generate client-facing reports

4. MEDIA BUYING AUTOMATION
   - Automate media buying workflows
   - Pull data from ad platforms (Facebook Ads Manager etc.)
   - Automate reporting and optimization tasks

5. SERVICE EXPANSION: TECH & AI CONSULTING
   - Website building for clients
   - Help companies convert to AI
   - Build personalized/specialized project management tools (same way we're building ours)
   - General IT consulting
   - Our own dashboard as a productized service for other companies
